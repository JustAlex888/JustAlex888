# JustAlex888 — World of Warcraft addons

Аддоны и compatibility-проекты для **World of Warcraft: Legion 7.3.5 / Interface 70300**.

| Аддон | Что делает | Ссылки |
|---|---|---|
| [CursorTrail 7.3.5 Extended](https://github.com/JustAlex888/CursorTrail-7.3.5-Extended) | Эффекты курсора, 2D/3D-слои и настраиваемый ореол с русской и английской локализацией. | [Репозиторий](https://github.com/JustAlex888/CursorTrail-7.3.5-Extended) · [Releases](https://github.com/JustAlex888/CursorTrail-7.3.5-Extended/releases) |
| [WoW Chat](https://github.com/JustAlex888/WoW-Chat) | История чата между сессиями, удобное копирование и резервное восстановление настроек Blizzard Chat. | [Репозиторий](https://github.com/JustAlex888/WoW-Chat) · [v1.0.1](https://github.com/JustAlex888/WoW-Chat/releases/tag/v1.0.1) |
| [XLoot Legion RU Filter](https://github.com/JustAlex888/XLoot-Legion-RU-Filter) | Companion для XLoot 7.3-3: русская локализация и дополнительный фильтр минимального item level. | [Репозиторий](https://github.com/JustAlex888/XLoot-Legion-RU-Filter) · [Releases](https://github.com/JustAlex888/XLoot-Legion-RU-Filter/releases) |
| [Outfitter 5.21 Legion](https://github.com/JustAlex888/Outfitter-5.21-Legion-7.3.5) | Compatibility-патч Outfitter для Legion 7.3.5 с обновлённым интерфейсом и локализацией. | [Репозиторий](https://github.com/JustAlex888/Outfitter-5.21-Legion-7.3.5) · [Releases](https://github.com/JustAlex888/Outfitter-5.21-Legion-7.3.5/releases) |
| [DBM RV*+](https://github.com/JustAlex888/DBM-RV-Star-Plus) | Неофициальный DBM-пакет для UWoW Legion с патчером, модулями подземелий и русским интерфейсом. | [Репозиторий](https://github.com/JustAlex888/DBM-RV-Star-Plus) · [Releases](https://github.com/JustAlex888/DBM-RV-Star-Plus/releases) |

## Важно

Скачивайте установочные архивы из раздела **Releases** конкретного проекта. GitHub автоматически созданные `Source code.zip` и `Source code.tar.gz` не всегда являются установочными пакетами.

Исходное авторство и лицензии указаны в README и лицензионных файлах каждого репозитория.
